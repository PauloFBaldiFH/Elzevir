Elzevir / Koha.Nexus - pacote de ícone de bandeja

- elzevir-tray-icon.ico -> ícone Windows com múltiplas resoluções
- elzevir-tray-icon.svg -> original vetorial
- elzevir-tray-icon-256.png -> PNG transparente principal
- elzevir-tray-icon-32.png -> PNG transparente útil para UI

Tamanhos incluídos no .ico:

Melhores tamanhos para ícone de bandeja:
- Windows: 16, 20 ou 24 px
- UI geral: 32 ou 48 px
- instalador / assets: 256 px
